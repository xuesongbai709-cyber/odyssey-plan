# 评分细则

## 四维锚点（1–5 分）

打分只问一句"哪一档最像"，不要精细到 4.5。理由必须写下来，分数没有理由等于没打。

### 资源 Resources

| 分 | 锚点 |
|---|---|
| 5 | 钱、时间、技能、人脉、作品、平台基本都在位，明天就能开工 |
| 4 | 缺一样，但半年内能补上，且已有替代方案 |
| 3 | 缺两样，需要主动攒 6–12 个月 |
| 2 | 缺三样以上，或缺的那一样（如资金、资质）不可替代 |
| 1 | 从零开始，且没有任何可借力的东西 |

### 喜爱度 Likeability

注意：评的是**过程**，不是结果。看"五年后的我多风光"不算。

| 分 | 锚点 |
|---|---|
| 5 | 说到日常环节时语速变快、有具体画面，不给钱也愿意做 |
| 4 | 大部分环节喜欢，少数环节要忍 |
| 3 | 说得出好处，但都是结果层面的好处；过程无感 |
| 2 | 主要靠"先忍几年"来支撑 |
| 1 | 想到就累，只是"应该做" |

### 自信度 Confidence

| 分 | 锚点 |
|---|---|
| 5 | 已经做过其中的关键动作，有成功经验可迁移 |
| 4 | 没做过，但有清晰的第一步和可参照的人 |
| 3 | 大致知道怎么开始，关键节点仍然模糊 |
| 2 | 描述里全是"如果……的话" |
| 1 | 完全不知道从哪下手，也没有可问的人 |

### 一致性 Coherence

打分依据只能是第 3 轮用户自己写的工作观/人生观。

| 分 | 锚点 |
|---|---|
| 5 | 直接兑现他的工作观和人生观，不需要任何解释 |
| 4 | 大方向一致，个别处需要妥协 |
| 3 | 一半对得上，另一半要靠"现实就是这样"来圆 |
| 2 | 明显冲突，需要长期忍 |
| 1 | 与他写下的价值观正相反 |

## 加权与总分

```
总分 = 资源×0.25 + 喜爱度×0.35 + 自信度×0.20 + 一致性×0.20
```

喜爱度权重最高，因为它是唯一无法长期靠意志力伪造的维度。资源可以攒，自信可以练，一致性可以谈；不喜欢，撑不过三年。

## 判定阈值

| 总分 | 最低维 | 结论 |
|---|---|---|
| ≥ 4.0 | ≥ 3 | **可全力推进**——先做原型验证，再谈执行 |
| 3.2 – 4.0 | ≥ 3 | **值得原型**——不要决定，先花一周拿信息 |
| 3.2 – 4.0 | ≤ 2 | **先补短板**——短板是资源就攒钱攒时间，是自信就先找一个人聊 |
| < 3.2 | 任意 | **暂缓**——不否决，但今年不作为主线，转入观察池 |
| 任意 | = 1 | **红线**——该方案不得进入执行，必须先解决那一维 |

## 四种打分偏差（发现就要当场纠）

1. **通胀**：全 4 分、全 5 分，不敢排序。→ 改用强制删除法。
2. **资源决定论**：资源 2 分就顺手把喜爱度也打 2 分。→ 四维要独立问，一次只问一维。
3. **沉没成本**：A 版喜爱度给 4 分，理由是"我都干了八年了"。→ 这是资源，不是喜爱。
4. **讨好**：察觉你在暗示某条更好，就顺着给分。→ 你先不给任何倾向，等分数齐了再说观察。

## 三条路放在一起看什么

单看分数不够，必看三个结构信号：

- **差值**：最高分与最低分差 < 0.3 → 三条路在他心里等价，真正的问题不是选路，是缺信息或缺动力
- **短板位置**：三条路的同一维都低（比如三条的一致性都是 2）→ 问题在标尺不在方案，回去重谈工作观
- **C 版分离度**：C 版喜爱度最高但资源最低，是健康结构——说明找到了渴望，缺的是移植方案；若 C 版喜爱度也低，说明这次访谈没挖到底，重做第 6 轮
